LE_ETERNALISM
Stage 1 is sent as two separate system prompts plus the chat history as proper role messages: player messages = user role, AI messages = assistant role (speaker name embedded in each message's content). Persona, character card, world info and preset prompts are excluded.

            Prompt library
            
Named modules that Stage 1 can activate. Trigger command: if this command appears in the Stage 1 output (e.g. [include: Combat Rules]), the module activates and its content is injected — otherwise it stays empty. If the trigger is empty, the module follows the include/exclude directives instead. With a variable set, insert the tag [[le_violence]] in the preset where the content should appear (same mechanism as Megumin's [[main_prompt]]).
