LE Eternalism — RPG Engine
Shows the combined prompt sent to the AI (all macros resolved, including \{{le_<variable>}}), captured from the last generation.
Analyzes the scene and applies the include/exclude variables to the preset. The preset itself then generates the reply (Stage 2).
Stage 1 is sent as two separate system prompts plus the chat history as proper role messages: player messages = user role, AI messages = assistant role (speaker name embedded in each message's content). Persona, character card, world info and preset prompts are excluded.


        
        

        
        

        

            Prompt library
            
Named modules that Stage 1 can include or exclude. If a module has a preset variable (e.g. violence), insert the tag [[le_violence]] into the preset where you want the module text to appear — the extension swaps it in before the request is sent (same mechanism as Megumin's [[main_prompt]]). While the module is inactive the tag is removed. The \{{le_<variable>}} macro form is also supported where macros resolve.
